# 🏦 Bank Management System (Python + Tkinter + MySQL)

A simple desktop-based Bank Management System built using Python Tkinter for GUI and MySQL (PyMySQL) for database management.  
This project allows users to perform basic banking operations like deposit, withdrawal, transfer, and transaction tracking.

---

## 📌 Project Overview

This project simulates a basic banking system where users can:
- Create an account
- Login securely
- Deposit money
- Withdraw money
- Transfer money to another user
- Check balance
- View transaction history

All data is stored in a MySQL database.

---

## 🚀 Features

### 👤 User Management
- User registration
- User login authentication
- Unique username validation

### 💰 Banking Operations
- Deposit money into account
- Withdraw money with balance validation
- Transfer money between users securely

### 📊 Account Services
- Check current balance
- View complete transaction history

### 🗄️ Database Features
- MySQL database integration
- Automatic table creation
- Transaction logging system

---

## 🛠️ Technologies Used

- Python 3.x
- Tkinter (GUI Library)
- PyMySQL (Database connectivity)
- MySQL Database
- datetime module
